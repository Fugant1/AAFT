# The main model to be fine-tuned in this repository is Audio Flamingo 3, possible fine-tuned versions are:
1. audio flamingo 3 + meld audio + iemocap audio (label adaptation).
2. audio flamingo 3 + meld (audio + transcript) + iemocap (audio + transcript), (label adaptation).
3. audio flamingo 3 + meld audio (multiple utterances to context) + iemocap audio (label adaptation), (multiple utterances to context).
